## `/api/buoy` (`netlify/functions/buoy.js`, NOAA NDBC latest observations)

- First call: HTTP 200 in 317 ms. `x-nexus-eye: buoy-v0.4.10`. `ok: true`, `source: "ndbc-latest-obs"`, `cached: false`.
- 807 stations kept, all with position and a valid observation time (`stats`: kept 807, noPosition 0, badTime 0, future 0, badRow 0, dupe 0).
- Observation span (UTC): newest 2026-11-27T11:05:00Z (5:05 AM CT), median 2026-11-27T10:30:00Z (4:30 AM CT), oldest 2026-11-27T08:05:00Z (2:05 AM CT). NDBC `Last-Modified`: 2026-11-27T11:00:30Z (5:00 AM CT). Median age at test time was well under the client's 3-hour LIVE ceiling.
- 52 stations sat in a Texas-coast bounding box (the client's TX/GULF region tags are applied in the page, not in the function). Sample TX-coast ids: 42002, 42032, 42033, 42034, 42035.
- Second call (in-memory cache): HTTP 200 in 1 ms, `cached: true`, same count.

The client layer is off unless the rail or `?layers=…,buoy` turns it on. Optional `?buoy=tx` / `?buoy=gulf`. LIVE needs a pull no more than 50 minutes old and a median station observation no more than 3 hours old. Dimmed dots are stations whose own observation is older than 3 hours. Missing values stay missing. Not a forecast.
